A focused command set for the daily work of the department.

Admin only

/shift-start

/shift-leaderboard

Shows all shift times on a leaderboard

/shift-end

Ends a shift

/shift-break

Starts a break for your shift

/shift-admin

Change shift data, admin only

/cite

Sends a citation in the channel

/arrest

Sends an arrest log in the correct channel
